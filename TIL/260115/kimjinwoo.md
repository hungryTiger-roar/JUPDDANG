## Jira 기본 개념

- **Project(프로젝트)**: 한 제품/팀/과제 단위 공간
- **Issue(이슈)**: 실제 일감(티켓). 종류는 보통
    - **Epic**: 큰 기능 묶음(“로그인 기능 전체”)
    - **Story/Task**: 실제 개발/업무 단위(“구글 로그인 버튼 추가”)
    - **Bug**: 버그
    - **Sub-task**: Task를 더 쪼갠 것
- **Workflow(워크플로우)**: 상태 흐름(예: To Do → In Progress → Review → Done)
- **Board(보드)**: 칸반/스크럼 보드 화면(이슈를 드래그로 상태 이동)
- **Backlog(백로그)**: 앞으로 할 일 목록(스크럼에서 특히 중요)
- **Sprint(스프린트)**: 1~2주 단위 계획/실행 묶음(스크럼)
- **Assignee / Reporter**: 담당자 / 생성자
- **Priority**: 우선순위
- **Labels / Components**: 태그/기능 영역 분류
- **Fix Version**: 배포 버전 묶음

## **이슈 만들기**

- 스페이스 → 프로젝트 선택 → + 만들기
- 업무 유형 선택
    - 에픽
        - 큰 단위 작업 (사용자 관리, 서버 관리 등)
    - 스토리
        - 에픽보다 작은 작업 (에픽이 사용자 관리라면 스토리는 사용자 등록, 사용자 로그인, 사용자 정보 수정 등)
    - 작업
        - 스토리보다 작은 작업
    - 버그
        - 버그 작업
- 필수 필드 채우기
    - **Summary**: 한 줄 제목 (예: “[OCR] 영수증 날짜 인식 오류 수정”)
    - **Description**: 상세(재현방법/요구사항/완료조건)
    - **Assignee**: 담당자
    - (있으면) **Epic Link** 또는 **Parent** 연결
- **첨부파일/이미지**, 링크(피그마/노션/PR) 붙이기
- 저장

## **담당자/검색/필터**

- Jira 검색창(JQL)로 원하는 이슈만 모을 수 있음
    
    자주 쓰는 예시:
    
    - 내 할 일: `assignee = currentUser() AND status != Done`
    - 특정 스프린트: `sprint in openSprints()`
    - 특정 Epic: `parentEpic = EPIC-123` (회사 설정에 따라 필드명 다를 수 있음)
    - 최근 생성: `created >= -7d`
