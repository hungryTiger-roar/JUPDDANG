> ## 기버-테이커 - 매쳐 
- 개발자 세계에서는 기버가 많고 공유하는 문화이다. 
- 자신의 성장과 목표를 놓치지 않고 꾸준히 간다. 
- 실패하는 기버는 타인을 돕는 만틈 나를 돌보지 않는다.
- 연민의 대상에 본인이 포함되지 않으면 그것은 이기적인 것이 아니다.

> ### 지라 기본 개념
- 실제 일감 (티켓) : 실제 일감, 종류는 보통
  - 에픽 : 큰 기능 묶음 ("로그인 기능 전체")
  - 스토리 : 사용자 관련 실제 개발/업무 단위 ("구글 로그인 버튼 추가)
  - 테스크 : 고객 외 실제 개발/업무 단위 ("개발 인프라, 회식 날짜 정하기")

 - 레이블
  - 해시태그 느낌으로, 새로 만들어서 넣을 수 있음

- 스토리포인트
  - 얼마나 걸리는지 표현
  - 난이도 분배를 위해 나눠둠

- 주로 사용할 기능
  - 컴포넌트, 릴리스, 칸반보드
