## 1. FE 개발의 변화: Tool이 곧 경쟁력이다

### '손 코딩' 시대의 종말
더 이상 모든 코드를 한 땀 한 땀 작성하는 시대는 지났다. 이제는 도구(Tool)를 얼마나 잘 활용하느냐가 개발자의 핵심 경쟁력이 된다.

### 🤖 AI Tool의 진화 과정

#### 1세대: 코딩 어시스턴트 (Assist)
단순한 코드 추천 및 자동 완성을 돕는 단계.
- **Gemini Code Assist**
- **AiCodeHelper**

#### 2세대: 프롬프트 그 이상 (Visual & Structure)
텍스트 프롬프트 없이 그림이나 UI를 통해 코드를 생성.
- **tldraw MakeReal:** 화이트보드에 그린 그림을 코드로 변환.



#### 3세대: AI Agent의 시대 (Autonomous)
단순 보조를 넘어, 스스로 판단하고 작업을 수행하는 에이전트 단계.
- **Cursor AI:** IDE 자체가 AI와 통합되어 코드베이스 전체를 이해하고 수정.
- **Copilot Antigravity:** (프로젝트/컨텍스트 인지 능력 강화)
- **활용 범위 확대:** 기획서 작성부터 **WebRTC**와 같은 복잡한 기술 구현까지 커버.

> **"어른들은 누구나 처음엔 어린이였다. 그러나 그것을 기억하는 이는 거의 없다."**
> - *어린왕자 中*
>
> *(기술의 발전 속에서 초심을 잃지 말 것, 혹은 AI라는 새로운 기술 앞에 우리 모두는 다시 어린이가 되어 배우는 과정이라는 의미)*

## 2. 애자일 소프트웨어 개발 선언 (Agile Manifesto)

### 4가지 핵심 가치
1. **공정과 도구**보다 **개인과 상호작용**을
2. **포괄적인 문서**보다 **작동하는 소프트웨어**를
3. **계약 협상**보다 **고객과의 협력**을
4. **계획을 따르기**보다 **변화에 대응하기**를

### 💡 주요 원칙 (Key Principles)
- **진척의 척도:** "작동하는 소프트웨어가 진척의 주된 척도이다."
- **유연성:** "비록 개발의 후반부일지라도 요구사항 변경을 환영하라."
- **소통:** "팀에서 정보를 전하는 가장 효율적이고 효과적인 방법은 면대면 대화이다."
- **단순성 (Simplicity):** "안 하는 일의 양을 최대화하는 기술이 필수적이다." (불필요한 작업 제거)
- **회고 (Retrospective):** "팀은 정기적으로 더 효과적인 방법을 숙고하고, 그에 따라 행동을 조율한다."

### 유저 검색 기능 추가 사항 요약

**1. 유저 검색 기능 구현 (Full-stack)**

* **UI 구현:** `SearchScreen`을 신설하여 검색 입력창, 버튼, 로딩/에러 메시지 등 다크 모드 기반의 검색 UI를 구현했습니다.
* **API 연동:** `AuthService`에 `searchUser` 메서드를 추가하여 `GET /api/account/profile/{targetId}` API를 호출하도록 구현했습니다.
* **로직 연결:** 검색 결과에 따라 성공 시 `ProfileScreen`으로 이동하고, 실패(404) 시 "해당 계정이 없습니다" 에러 메시지를 노출하는 예외 처리를 완료했습니다.

**2. 피드 및 글쓰기 화면 UI 개선**

* **진입점 수정:** `FeedScreen` 상단의 가로 스크롤(유저 리스트)을 제거하고, 헤더 우측에 검색 버튼(돋보기)을 배치하여 접근성을 높였습니다.
* **테마 통일:** `CommunityComposeScreen`(글쓰기)의 배경색, 입력창, 카드 UI 등을 앱 전체 테마인 \*\*Dark Mode(`0xFF141414`)\*\*로 통일하여 일관성을 확보했습니다.
