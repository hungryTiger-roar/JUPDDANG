## 📅 2026. 02. 05

### 2. Flutter UI 키보드 시인성 문제 해결과 Focus 관리

입력 필드 활성화 시 키보드가 주요 UI 요소(하단 버튼 등)를 가리거나, 입력 종료 후에도 내려가지 않는 문제를 **`FocusScope`**와 **`GestureDetector`**를 활용해 제어하여 사용자 경험(UX)을 개선했습니다.

#### 📌 키보드 영역 간섭(Overflow) 해결과 UX 최적화

* **문제 상황 (Issue)**
* `TextField` 입력 시 소프트 키보드가 올라오면서 하단 고정 버튼(Bottom Button)이나 중요 정보를 가리는 현상 발생 (`RenderFlex overflowed` 경고 동반 가능성).
* 입력을 마치고 화면의 빈 공간을 터치했음에도 키보드가 내려가지 않아, 사용자가 뒤로 가기 버튼을 눌러야 하는 불필요한 depth 발생.


* **해결 전략 (Solution)**
* **Focus 제어 (Unfocusing):** `Scaffold`의 body나 최상위 컨테이너를 `GestureDetector`로 래핑(Wrapping).
* **이벤트 바인딩:** `onTap` 이벤트 발생 시 `FocusScope.of(context).unfocus()`를 호출하여, 포커스를 해제하고 자연스럽게 키보드가 내려가도록 구현.
* **화면 크기 대응:** `Scaffold`의 `resizeToAvoidBottomInset` 속성을 상황에 맞게 제어하여, 키보드 등장 시 레이아웃이 찌그러지지 않고 유연하게 반응하도록 조정.



> **💡 오늘의 교훈**
> **"사용자 경험(UX)은 '보이지 않는 배려'에서 완성된다."**
> 사용자가 키보드를 내리기 위해 별도의 버튼을 찾게 해서는 안 된다. 화면의 빈 곳을 누르는 본능적인 행동이 자연스럽게 기능으로 연결될 때, 앱은 비로소 '도구'가 아닌 '환경'이 된다.
