## SNS UX & UI 리팩토링
### 변경 사항 요약

**1. 피드 UI 레이아웃 및 디자인 개선**

* **콘텐츠 배치 수정:** 기존 `[사진] -> [좋아요/댓글] -> [내용]` 순서를 **`[사진] -> [내용] -> [좋아요/댓글]`** 순서로 변경하여 가독성을 높임
* **불필요한 UI 제거:** 사용 빈도가 낮은 '신고하기(Flag Icon)' 버튼을 삭제

**2. 편의 기능 및 로직 강화**

* **스크롤 최상단 이동:** 하단 네비게이션의 SNS 탭(커뮤니티 아이콘)을 다시 클릭하면 피드 최상단으로 자동 스크롤되는 기능 구현 (`ScrollController` 적용)
* **날짜 포맷 고도화:** 게시글 작성 시간을 더 직관적으로 변경
  * 1분 미만: `방금`
  * 1시간 미만: `n분 전`
  * 24시간 미만: `n시간 전`
  * 7일 미만: `n일 전`
  * 그 외: `yyyy년 MM월 dd일`
* **유저 리스트 버그 수정:** 로그인 상태임에도 상단 가로 스크롤 영역에 "로그인 후 유저 목록을 확인할 수 있어요" 문구가 노출되던 문제를 해결 (계정 정보가 있으면 리스트가 정상 노출되도록 조건문 수정)
