### 2.2 환경 변수 설정 (.env)
프로젝트 루트(`S14P11D208/Backend`) 또는 배포 디렉토리(`/home/gitlab-runner/app`)에 `.env.prod` 파일을 생성해야 합니다.

**필수 환경 변수 목록:**
```properties
# [Project Info]
ENV_TYPE=prod
PROJECT_NAME=jupddang-prod
GCP_CREDENTIALS_PATH=/app/gcp-credentials.json
FIREBASE_CONFIG_PATH=/app/config/firebase-adminsdk.json

# [Ports]
APP_PORT=50001
DB_PORT=60001
REDIS_PORT=60002

# [Database]
POSTGRES_USER=jupddang
POSTGRES_PASSWORD=[비밀번호]
POSTGRES_DB=jupddang_prod
DB_HOST=jupddang-db-prod
DB_PORT=5432

# [Redis]
REDIS_HOST=jupddang-redis-prod
REDIS_PORT=6379

# [Spring]
SPRING_PROFILES_ACTIVE=prod
SPRING_DATASOURCE_URL=jdbc:postgresql://jupddang-db-prod:5432/jupddang_prod
SPRING_DATASOURCE_USERNAME=jupddang
SPRING_DATASOURCE_PASSWORD=[비밀번호]

# [External Keys]
GEMINI_API_KEY=[Google Gemini API Key]
GEMINI_API_URL=[Gemini API Endpoint]
MAPBOX_ACCESS_TOKEN=[Frontend용이지만 참고]
```

### 2.3 Docker 컨테이너 실행
```bash
# Backend/jupddang 디렉토리 또는 docker-compose.yml이 있는 위치에서 실행
docker compose up -d --build
```
*   `--build`: 이미지를 새로 빌드하여 시작
*   `-d`: 백그라운드 실행

### 2.4 배포 시 특이사항
1.  **Firebase/GCP 키 파일**:
    *   `jupddang-firebase.json` (Firebase Admin SDK) -> `/home/gitlab-runner/config/firebase/` 위치에 필수
    *   `gcp-credentials.json` (Google Cloud Storage) -> 프로젝트 루트에 필수
2.  **SSL 인증서**:
    *   Nginx 컨테이너가 `/etc/letsencrypt`를 볼륨으로 마운트하여 사용 중입니다.
    *   `certbot`을 통해 갱신된 인증서가 호스트 경로에 존재해야 합니다.

## 3. 주요 설정 파일 명세 (Key Configuration Files)
서버 구축 시 반드시 아래 파일들을 해당 경로에 생성해야 정상 작동합니다.

### 3.1 Nginx 설정 (`infra/nginx/default.conf`)
외부 요청을 각 컨테이너(Backend, Grafana 등)로 라우팅하는 리버스 프록시 설정입니다.
`/home/gitlab-runner/infra/nginx/default.conf` 경로에 위치합니다.

```nginx
server {
    listen 80;
    server_name i14d208.p.ssafy.io;
    client_max_body_size 20M;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name i14d208.p.ssafy.io;
    client_max_body_size 20M;

    ssl_certificate /etc/letsencrypt/live/i14d208.p.ssafy.io/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/i14d208.p.ssafy.io/privkey.pem;

    # [Backend API 및 WebSocket]
    location /dev-api/ws/ {
        proxy_pass http://jupddang-backend-dev:8080/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }

    location /dev-api/ {
        proxy_pass http://jupddang-backend-dev:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # [Swagger]
    location /swagger-ui {
        proxy_pass http://jupddang-backend-dev:8080;
        proxy_set_header Host $host;
    }
    location /v3/api-docs {
        proxy_pass http://jupddang-backend-dev:8080;
        proxy_set_header Host $host;
    }

    # [Grafana]
    location /monitor {
        proxy_pass http://jupddang-grafana:3000;
        proxy_set_header Host $host;
    }
}
```

### 3.2 인프라 Docker Compose (`infra/docker-compose-infra.yml`)
Nginx, Grafana, Prometheus 등 기반 인프라를 실행하는 설정입니다.

```yaml
version: '3.8'

services:
  nginx:
    image: nginx:latest
    container_name: jupddang-nginx
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/default.conf:/etc/nginx/conf.d/default.conf
      - /etc/letsencrypt:/etc/letsencrypt:ro
    networks:
      - jupddang-net
    restart: always

  prometheus:
    image: prom/prometheus
    container_name: jupddang-prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./monitoring/prometheus.yml:/etc/prometheus/prometheus.yml
    networks:
      - jupddang-net

  grafana:
    image: grafana/grafana
    container_name: jupddang-grafana
    networks:
      - jupddang-net
    environment:
      - GF_SERVER_ROOT_URL=https://i14d208.p.ssafy.io/monitor/
      - GF_SERVER_SERVE_FROM_SUB_PATH=true

# [Network] 외부 네트워크가 아닌 직접 생성
networks:
  jupddang-net:
    external: true
    name: jupddang-network
```

### 3.3 애플리케이션 Docker Compose (`app/docker-compose.yml`)
Backend 서버, DB, Redis를 실행하는 메인 설정입니다.

```yaml
version: '3.8'

services:
  # [Production]
  backend-prod:
    container_name: jupddang-backend-prod
    image: jupddang-backend:prod
    env_file: .env.prod
    volumes:
      - ./gcp-credentials.json:/app/gcp-credentials.json
      - /home/gitlab-runner/config/firebase/jupddang-firebase.json:/app/config/firebase-adminsdk.json:ro
    networks:
      - jupddang-net
    ports:
      - "127.0.0.1:50001:8080"
    depends_on:
      - db-prod
      - redis-prod

  db-prod:
    container_name: jupddang-db-prod
    image: postgis/postgis:15-3.4
    volumes:
      - /home/gitlab-runner/data/prod/db:/var/lib/postgresql/data
    networks:
      - jupddang-net
    ports:
      - "127.0.0.1:60001:5432"

  redis-prod:
    container_name: jupddang-redis-prod
    image: redis:alpine
    networks:
      - jupddang-net
    ports:
      - "127.0.0.1:60002:6379"

  # [Development] (동일 구조, 포트 50003/60003/60004 사용)
  backend-dev:
    # ... (생략, 위 Prod와 유사)

networks:
  jupddang-net:
    external: true
    name: jupddang-network
```
