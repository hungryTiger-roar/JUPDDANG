# 외부 서비스 정보 수집 (External Services)

본 프로젝트(`S14P11D208`)에서 활용 중인 외부 서비스(SaaS/PaaS/API) 목록 및 상세 정보입니다.

## 1. 지도 및 위치 서비스 (Maps & Location)

### **Mapbox**

- **용도**: 모바일 앱(Flutter) 내 지도 타일 렌더링 (Frontend)
- **사용 라이브러리**: `flutter_map`, `latlong2`
- **필요 정보**:
  - **Access Token**: `.env` 파일 내 `MAPBOX_ACCESS_TOKEN`
  - **Style URL**: `mapbox://styles/mapbox/light-v10` (또는 유사 스타일)

### **Uber H3**

- **용도**: 전 세계를 육각형 그리드로 나누어 위치를 인덱싱 (Plogging 경로 및 점령 시스템)
- **사용 라이브러리**:
  - Backend: `com.uber:h3:4.4.0`
  - Frontend: `h3_flutter`
- **비고**: 별도 API 키 불필요 (오픈소스 라이브러리), Resolution 9 사용

---

## 2. AI 및 데이터 처리 (AI & Data)

### **Google Gemini API**

- **용도**: 플로깅 중 쓰레기 사진을 분석하여 자동 식별 (Trash Detection)
- **사용 라이브러리**: `spring-boot-starter-webflux` (REST API 호출)
- **필요 정보**:
  - **API Key**: `GEMINI_API_KEY` (Backend Config)
  - **API URL**: `GEMINI_API_URL`
- **구현 위치**: `TrashDetectionServiceImpl.java`

---

## 3. 클라우드 인프라 및 스토리지 (Cloud & Storage)

### **Google Cloud Platform (GCP)**

#### **Google Cloud Storage (GCS)**

- **용도**: 사용자 프로필 이미지, 플로깅 인증샷, 맵 캡쳐 이미지 저장
- **사용 라이브러리**: `spring-cloud-gcp-starter-storage`
- **필요 정보**:
  - **Credentials**: `gcp-credentials.json` (Service Account Key)
  - **Bucket Name**: `jupddang-images`

### **Firebase**

#### **Firebase Cloud Messaging (FCM)**

- **용도**: 앱 푸시 알림 (플로깅 종료, 친구 요청 등)
- **사용 라이브러리**:
  - Backend: `firebase-admin`
  - Frontend: `firebase_messaging`
- **필요 정보**:
  - **Service Account Key**: `jupddang-firebase.json` (Backend)
  - **Android Config**: `google-services.json` (Frontend Build 타임 필요)

---

## 4. 인증 및 보안 (Auth & Security)

### **자체 인증 (Custom Auth)**

- **방식**: JWT (Access Token + Refresh Token)
- **OAuth 사용 여부**: **미사용** (현재 ID/PW 기반 회원가입/로그인만 구현됨)
- **구현 위치**: `AuthService.java`, `AccountService.java`

---

## 요약: 관리자 준비 필요 파일 목록

1.  `gcp-credentials.json` (GCS 접근용)
2.  `jupddang-firebase.json` (FCM 서버 전송용)
3.  `google-services.json` (Android 앱 빌드용)
4.  `.env` (API Key 포함: Gemini, Mapbox 등)
