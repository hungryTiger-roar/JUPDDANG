# 시연 시나리오: 줍땅 (Jupddang) 플로깅 & AI 검증

## 1. 개요
*   **목적**: 플로깅 활동의 실시간 그리드 점령, AI 기반 청소 검증, 커뮤니티 공유 기능을 흐름에 따라 시연.
*   **인원**:
    *   **플로깅 러너 (1명)**: 실제 앱을 들고 이동하며 플로깅 수행.
    *   **촬영자 (1명)**: 러너의 활동 모습을 Webex로 중계.

## 2. 사전 준비
*   **플로깅 러너**: `MapScreen` 진입, GPS 수신 확인. 데이터 통신 상태 점검.
*   **촬영자**: Webex 미팅룸 입장, 카메라 ON, 러너의 모습을 잘 담을 수 있는 위치 선정.
*   **관제(발표자)**: Webex 화면과 앱 화면(미러링)을 번갈아 보여줄 준비.

---

## 3. 시나리오 단계

### Step 1: Webex 중계 & 플로깅 시작 (Intro)
*   **화면**: Webex 전체 화면 (러너 모습)
*   **내용**:
    1.  러너가 플로깅 복장을 갖추고 대기하는 모습 송출.
    2.  러너가 앱에서 **‘플로깅 시작’** 버튼을 누름.
    3.  러너가 이동 시작 (가볍게 뛰거나 걷기).

### Step 2: 실시간 그리드 점령 (MapScreen)
*   **화면**: 앱 미러링 화면 (`MapScreen`) + Webex PIP(Picture-in-Picture) 또는 분할 화면
*   **내용**:
    1.  **실시간 위치 이동**: 러너의 이동에 따라 맵 상의 캐릭터(`PixelCharacter`)가 이동.
    2.  **그리드 점령 시각화**:
        *   러너가 이동함에 따라 바닥의 육각형 그리드(H3 Hexagon) 색상이 서서히 차오름 (`_occupyProgress` 증가).
        *   기존에 비어있던 그리드가 러너의 색상(예: 초록색/파란색)으로 변경됨을 강조.
        *   **Point**: "지금 보시는 것처럼 이동 경로에 따라 실시간으로 땅을 점령하고 있습니다."

### Step 3: 쓰레기 발견 및 AI 검증 (Quest / Verification)
*   **화면**: 앱 미러링 화면 (`QuestModal`) + Webex (쓰레기 줍는 모습)
*   **내용**:
    1.  **쓰레기 발견**: 러너가 쓰레기(페트병, 캔 등)를 발견하고 멈춤.
    2.  **퀘스트 모드 진입**: 앱 화면 우측의 **'Q' 버튼**(`QuestButton`) 터치하여 퀘스트 모달 진입.
    3.  **Before 촬영**: **'Before'** 슬롯을 터치하여 쓰레기가 있는 상태 촬영 (`ImagePicker`).
    4.  **청소 수행**: (Webex 화면) 러너가 쓰레기를 줍고 봉투에 담음.
    5.  **After 촬영**: **'After'** 슬롯을 터치하여 깨끗해진 바닥 촬영.
    6.  **AI 검증 요청**: **'검증하기'** 버튼 터치 -> `QuestService`를 통해 AI 서버로 전송.
    7.  **검증 결과 확인**:
        *   AI 분석 완료 알림.
        *   **"쓰레기 N개 획득!"** 메시지와 함께 보상(코인 등) 획득 화면 노출.
        *   **Point**: "AI가 전후 사진을 비교하여 실제로 청소가 되었는지, 쓰레기가 몇 개인지 검증합니다."

### Step 4: 플로깅 종료 및 커뮤니티 업로드 (Social)
*   **화면**: 앱 미러링 화면 (`CommunityComposeScreen`)
*   **내용**:
    1.  **플로깅 종료**: 목표 달성 후 **‘종료’** 버튼 길게 누르기 -> 결과 화면 확인.
    2.  **커뮤니티 이동**: 하단 탭을 통해 커뮤니티(`FeedScreen`) 또는 결과 화면에서 **'공유하기'** 버튼 터치.
    3.  **글 작성 (`CommunityComposeScreen`)**:
        *   **기록 불러오기**: 방금 수행한 플로깅 기록(지도 경로, 거리, 시간)이 자동으로 첨부되거나 선택.
        *   **사진 첨부**: 퀘스트 수행 시 찍은 검증된 Before/After 사진을 선택하여 첨부.
        *   **내용 작성**: "오늘도 지구 한 조각 줍기 성공!" 등의 멘트 입력.
    4.  **업로드**: **'PUBLISH'** 버튼 터치 -> 피드에 게시물 등록 완료.
    5.  **피드 확인**: 커뮤니티 피드 리스트에 방금 올린 게시글이 최상단에 뜨는 것 확인.

---

## 4. 기술적 포인트 (참고용)
*   **Map**: `LocationH3Service`를 이용한 실시간 H3 Grid 렌더링.
*   **Socket**: `PloggingSocketService`를 통한 위치 동기화.
*   **AI**: `QuestService.validateQuest`를 통해 이미지 분석 및 쓰레기 카운팅.
*   **UI**: NES 스타일의 레트로 감성 UI (`Nes_UI`, `PixelArtIcons`) 적용.
